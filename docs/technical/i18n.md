# Internationalization (i18n)

> Last updated: 2026-06-01

ELETTRA supports four languages with a custom translation system.

---

## Supported languages

| Code | Language |
|------|----------|
| `en` | English |
| `de` | German |
| `fr` | French |
| `it` | Italian |

---

## How it works

### Translation source

All translations are defined in `src/i18n/translations.js` as a single object:

```javascript
export const translations = {
  en: { "nav.fleet": "Fleet", ... },
  de: { "nav.fleet": "Flotte", ... },
  fr: { "nav.fleet": "Flotte", ... },
  it: { "nav.fleet": "Flotta", ... },
};
```

### Translation function

```javascript
import { t } from "../i18n";

const label = t("nav.fleet"); // Returns translated string for current language
```

The `t()` function:
- Looks up the key in the current language
- Falls back to the key itself if not found
- Supports parameter interpolation: `t("key", { count: 5 })` replaces `{count}` in the string

### DOM application

`applyTranslations(lang)` traverses the DOM and updates elements with `data-i18n` attributes:

```html
<span data-i18n="nav.fleet">Fleet</span>
```

This is called:
- On initial page load
- After navigation (new partial loaded)
- When language changes

### Language change

- Language is stored in localStorage
- Changing language dispatches `I18N_CHANGE_EVENT`
- The navigation system listens and reloads the current page with the new language

Source: `src/i18n/index.js`

## Key naming convention

Keys follow a hierarchical dot notation:

```
section.subsection_detail
```

Examples:
- `nav.fleet` — Navigation: Fleet label
- `simulation.col_name` — Simulation page: column header "Name"
- `yearly_analysis.env_kpi_co2_equiv` — Yearly analysis: CO₂ equivalent label
- `common.delete` — Shared: Delete button
- `about.title` — About page: title

### Common prefixes

| Prefix | Usage |
|--------|-------|
| `nav.*` | Navigation labels |
| `common.*` | Shared UI elements (buttons, labels) |
| `simulation.*` | Feasibility evaluation pages |
| `yearly_analysis.*` | Yearly analysis pages |
| `fleet.*` | Fleet management pages |
| `about.*` | About page |
| `header.*` / `footer.*` | Shell chrome |
| `pagination.*` | Pagination controls |

## Adding a new translation

1. Add the key to all four language objects in `src/i18n/translations.js`:

```javascript
en: { ..., "my_section.new_key": "English text" },
de: { ..., "my_section.new_key": "German text" },
fr: { ..., "my_section.new_key": "French text" },
it: { ..., "my_section.new_key": "Italian text" },
```

2. Use in JavaScript:

```javascript
const label = t("my_section.new_key");
```

3. Or in HTML with automatic translation:

```html
<span data-i18n="my_section.new_key">English text</span>
```

The inline text serves as the default/fallback if the key is missing.
